# 知伴 · 画像驱动的通用家教界面

React + Vite，面向学生和陪伴学习的家长。题目、学科、学习阶段和讲解偏好均可自由填写，不通过预设题型限制输入。

## 本地运行

```powershell
npm install
npm run dev
```

默认连接 `http://127.0.0.1:8000`。更换服务地址时，在启动或构建之前设置：

```powershell
$env:VITE_API_BASE_URL = 'http://127.0.0.1:8000'
npm run dev
```

生产构建：`npm run build`。生成目录为 `dist/`。

## 学习流程

1. 填写学生编号并切换，加载该学生的独立画像。设置阶段、目标、教材、兴趣、语言、偏好和节奏，保存后用于讲解。开始讲解时也会先保存尚未保存的画像修改。
2. 输入完整题意、材料、代码或其他学习任务，学科可自动识别或自由填写。可提供完整作答过程、辅导目标及补充信息，也可上传最多 4 张 PNG/JPG/WebP 图片，每张不超过 5 MB。图片发送给后端，能否理解图片取决于已配置模型的视觉能力。
3. 查看作答依据、分步讲解、为什么采用当前讲法、理解检查与练习。参考解答默认折叠；信息不足或模型不可用时，明确展示补充问题或不可用状态。
4. 在当前会话中回答引导问题、补充信息、继续追问或请求换一种讲法。此前轮次可以展开查看。
5. 填写练习作答后，把练习与作答带入新题，再点击开始学习。原题、旧附件与旧会话会清空，避免把练习回答作为原题的新答案。
6. 反馈讲解是否有用、是否理解及具体困难。画像展示作答中观察到的展现次数、待支持次数和最近证据，不显示推测的掌握概率。

## 服务接口

- `GET /health`：服务及模型配置状态。
- `GET /api/v1/profiles/{student_id}`、`PUT /api/v1/profiles/{student_id}`：读取和保存画像。
- `POST /api/v1/tutor`：通用题目讲解，携带画像所属学生、会话、作答、图片、追问和讲解策略偏好。
- `POST /api/v1/feedback`：记录当前讲解反馈。

网络失败后不编辑内容，重复提交沿用原 `request_id`；修改内容会生成新请求标识。同一作答的追问沿用 `attempt_id`，修改作答产生新的作答标识。修改题干或学科、增删图片、开始新题或切换学生都会重置会话。请求期间锁定相关表单，同时检查学生和会话版本，避免异步结果串入其他学生。

## 当前范围

- 当前页面保留多轮记录；刷新后可重新读取服务端画像，但尚无历史会话列表或会话恢复入口。
- 文本按原始换行展示，保留代码缩进；尚未加入 Markdown、数学公式排版或代码高亮依赖。
- 学生编号用于本地原型的数据区分，页面没有账户登录或权限管理功能。
